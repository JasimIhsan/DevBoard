Click any task card to open its **detail panel**. Almost everything saves automatically as you edit.

## Creating tasks

- Press `C` anywhere (when not typing) to open the *New task* dialog.
- Use the **New task** button in the top bar.
- Use the **+** on a board column or the quick-add row in the backlog.

Only a title is required. New tasks go to the **backlog** unless you choose a column in the *Add to* field (a column's **+** button picks that column for you).

## Fields

Set the **type**, **priority**, **estimate**, **labels**, **due date** and **column** from the detail panel. Choosing **Backlog** as the column sends the task back to the backlog. See [Core concepts](/docs/concepts) for what each one means.

## Description

The description supports Markdown: headings, lists, links, tables and code blocks. Use it for context and **acceptance criteria**, the conditions that must be true for the task to be done.

## Subtasks

Add small steps as a checklist and tick them off as you go. The card shows progress such as `2/5`.

## Comments

Leave notes, questions or findings. Comments support Markdown and are timestamped. AI assistants connected through [MCP](/docs/mcp-overview) can comment too.

## Development

Every task has a suggested **git branch name**, for example `core-12-add-rate-limiting`. Copy the ready-made `git checkout -b …` command, or type your own branch name. You can also store a pull request link.

## Activity

The activity log records changes such as column moves, archiving and edits so you can see how a task evolved.

## Deleting a task

Use the trash icon in the detail panel and confirm. Deleting removes its subtasks and comments permanently.

Projects keep unrelated work apart. Manage them from **Projects** in the sidebar.

## Create a project

Click **+** beside *Projects*, or choose **Create project** in the command palette. Enter a name, a key (2 to 5 letters recommended) and optionally a description and colour.

> **Warning** The key cannot be changed later because every task key is built from it.

## Edit a project

On the **Projects** page, open a project's menu and choose **Edit** to change its name, description or colour.

## Star a project

Click the star beside a project in the sidebar or on the Projects page. Starred projects move to a **Starred** group at the top of the sidebar.

## Archive and restore

Archive a project when the work is finished but you want to keep the history.

- It is hidden from the sidebar, dashboard, all-projects board, search and *Recent*.
- Opening it directly shows an **Archived** banner. You can still read, edit and move existing tasks.
- You **cannot** add tasks, add columns or import CSV until you restore it.
- Archiving removes the star. Restoring does not bring it back.

Restore from the banner, or from the **Archived** section of the Projects page.

## Delete a project

Deleting removes the project with all its tasks (archived ones too), columns and comments. You must type the project key to confirm.

> **Tip** If you are unsure, archive instead. Archiving is fully reversible; deleting is not.

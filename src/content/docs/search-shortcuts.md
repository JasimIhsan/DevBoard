DevBoard is designed to be fast to drive from the keyboard.

## Command palette

Press `⌘K` (macOS) or `Ctrl+K` (Windows and Linux) from any page. You can:

- **Search tasks** by title, label or key (try `CORE-12`).
- **Jump** to a project's board or backlog.
- **Run actions** such as creating a task or project, opening the dashboard or installing the app.
- Open **documentation** pages.

With the box empty, the palette lists your most recent tasks.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Open the command palette. |
| `C` | Create a task (when not typing in a field). |
| `T` | Open your [to-dos](/docs/todos) (when not typing in a field). |
| `Enter` | Open the focused task card. |
| `Space` + arrows | Pick up and move a card with the keyboard. |
| `Esc` | Close dialogs and panels. |

## Recent

The **Recent** menu in the sidebar lists the projects you worked in lately, newest first, like Jira's *Recent* list. Each project appears once; opening one takes you to the board or backlog you were last on. It is saved on the server, so it follows you across devices.

> **Note** There are no accounts, so Recent is shared by every device that opens this app. Use **Clear** in the menu to reset it.

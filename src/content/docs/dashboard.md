Two views help you see work across every project.

## Dashboard

The **Dashboard** is the home page. It summarises what needs attention:

- **Headline numbers:** open tasks, tasks in progress, open P0 tasks and tasks done this week.
- **Boards:** one card per project with the number of tasks in each column, how many are in the backlog, and progress (tasks and points done).
- **In progress across projects:** every task currently being worked on.
- **Due soon & overdue:** tasks that need action first.
- **Recently completed:** what shipped lately.

Archived projects are left out so the numbers reflect live work.

## All-projects board

**All projects board** in the sidebar combines the boards of every project into one view with three lanes: **To do**, **In progress** and **Done**. Use it for a single daily view of everything in flight.

- Each card shows its project key so you know where it belongs.
- Drag and drop works exactly like the project board.
- Filters apply across all projects.

- Each card shows the name of the column it is really in, such as *In Review*.
- Dragging a card to another lane moves it to the first column of that type in its own project.

> **Note** Only tasks that are on a board appear here. Backlog and archived tasks don't.

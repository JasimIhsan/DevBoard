The **Board** shows the tasks of the project's active sprint as cards in four columns.

## Columns

| Column | Use it for |
| --- | --- |
| **To Do** | Planned work that has not started. |
| **In Progress** | Work being done now. |
| **In Review** | Finished work waiting for a check. |
| **Done** | Completed work. |

Each column header shows the number of cards and the total points.

## Moving cards

Drag a card to another column, or reorder it within its column. The change saves immediately and the card stays where you drop it. Order is preserved, so the top card is your next priority.

- **Keyboard:** focus a card, press `Space` to pick it up, use the arrow keys to move it and `Space` again to drop.
- **Mobile:** the board shows one column at a time with tabs to switch between columns.

## Filters

The bar above the board lets you narrow the cards:

- **Filter tasks…** searches titles, keys and labels.
- **Priority**, **Type** and **Label** dropdowns limit the cards shown.

Filters only affect what you see. They never change your tasks.

## The sprint header

The header shows the sprint name, goal, dates and progress (tasks and points done). From here you can **Complete sprint**.

## When there is no board

The board needs an **active sprint**. If none is running, go to the [Backlog](/docs/backlog-sprints) to create and start one.
